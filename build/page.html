Untitled site – CAM Tool Web ODOT Crash Analysis Module

Setup & inputs

Export a crash file from AASHTOWare Safety using the GCAT Format query, then load the CSV here. Everything is computed in this page — nothing is uploaded.

Drop a GCAT CSV export here

Or choose a file. The tool reads the same columns the CAM Tool’s TIMS – GCAT Import reads, matched by column name.

Quick summary

Counts and percentages across every crash-level field, matching the CAM Tool’s Quick Summary sheet.

Crash analysis

Severity, harm and exposure crosstabs, with crashes by year, hour, month and type.

Unit 1 analysis

Everything the report records about unit 1 — typically the at-fault vehicle.

Relative severity index

Average crash cost per crash at this site, weighted by crash type against the statewide cost table.

Proportions

How this site’s crash mix compares with the statewide average for a site of the same type.

Emphasis area

Fatalities and serious injuries by Ohio Strategic Highway Safety Plan target group, year by year.

Crash tree

Crashes split by intersection relation, then by roadway departure and traffic control, with the ranked crash types on each branch.

Collision diagram

An intersection collision diagram built from the at-fault unit’s crash type and travel directions. Click a symbol for the crash behind it.

Full crash data

The decoded crash table — every field, and every field is editable. Column A links to the OH-1 report on the ODOT crash report service. Edits here update every other sheet immediately; download a copy with the changed cells highlighted for ODOT’s crash data cleanup process.
