Reproduces the analysis of ODOT’s Crash Analysis Module (CAM) Tool workbook. Code lookups, the relative severity index cost table and the statewide proportions are taken from the workbook’s own reference sheets (proportions data set: AASHTOWare Safety, 2021–2025, updated June 2026). This is an independent re-implementation and is not published by the Ohio Department of Transportation.
